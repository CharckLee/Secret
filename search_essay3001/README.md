# LitMind · AI 文献精读与轻量化管理平台

面向大学生、生物医药、理工科科研人员的轻量化 AI 文献管理精读 Web 平台。  
摒弃 Zotero、EndNote 臃肿复杂，主打轻量、即用即走、AI 自动解析、笔记联动、一键国标引用。

## 项目定位

### 真实痛点
- Zotero/EndNote 太重、配置繁琐，不适合学生快速上手
- 大量 PDF 文献堆积，无法快速筛选核心结论
- 英文文献难懂，逐篇精读耗时极大
- 文献笔记零散，和原文无法联动对照
- 写论文参考文献格式混乱，手动改 GB/T7714 极其耗时
- 多篇文献观点无法横向对比、梳理研究差异

### 技术栈
Next.js 16 + TypeScript + TailwindCSS + Prisma + SQLite + 前端文件解析  
纯轻量化本地项目，无需后端服务器，适合课程项目 / 科创作品 / 作品集。

## 核心功能

### PDF 上传与智能解析
- 单篇/批量 PDF 上传
- 自动解析文本，提取标题、作者、摘要、关键段落、研究方法、实验结论

### AI 文献智能精读
对全文进行 AI 结构化提炼：
- 自动生成中文摘要（200-300 字）
- 提取 5-10 个核心关键词
- 梳理研究目的、实验方法、创新点、局限性、核心结论
- 英文文献自动翻译关键段落

### 标签分类管理
- 自定义标签创建、编辑、删除
- 文献多标签绑定
- 按标签筛选 + 搜索文献标题、关键词、正文

### 文献专属笔记联动
- 每篇文献独立笔记面板
- 笔记与文献永久绑定，2 秒 debounce 自动保存

### 多文献平行对比分析
- 支持 2-5 篇文献横向对比
- AI 自动输出对比维度：研究对象、实验方法、数据结果、创新点、不足
- 对比界面内置关键词智能检索 + 位置定位双模式
- 对比界面批量管理（删除、改标签、导出）

### 国标参考文献导出
- 一键生成 GB/T7714 格式
- 支持单篇/批量导出，可直接复制粘贴到论文

## 页面结构

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页 | `/` | 文献卡片网格、搜索、标签筛选、上传、批量对比入口 |
| 文献预览 | `/literature/[id]/preview` | 摘要、关键词、AI 概述、查看原文入口 |
| 文献详情/AI精读 | `/literature/[id]` | PDF 预览、AI 结构化精读、笔记编辑、引用导出 |
| 文献对比 | `/compare?ids=1,2,3` | 平行对比、关键词总结、位置检索、批量管理 |
| 关键词位置检索 | `/compare/search` | 全文关键词高亮定位 |
| 标签管理 | `/tags` | 标签 CRUD |

## 数据库设计

```
Literature — id, title, author, abstract, content, keywords, pdfPath,
             journalSource, journalUrl, aiAnalysis, aiOverview,
             translatedContent, createTime, updateTime
             → tags (多对多), notes (一对多)

Note      — id, literatureId, content, createTime

Tag       — id, name, color
             → literature (多对多)
```

## UI 规范
- 风格：学术极简、低饱和、浅蓝/淡青主色调
- 卡片 hover：scale 1.02 + shadow-lg + 200ms 过渡
- 响应式：电脑端为主、适配平板

## 禁止开发内容
- 社区、评论、社交、积分、会员、付费
- 复杂用户权限、管理员后台
- 云端存储、付费服务器
- 违规深度爬虫、破解期刊权限

## 快速开始

```bash
npm install
cp .env.example .env   # 编辑填入 AI_API_KEY
npx prisma migrate dev
npx prisma db seed
npm run dev             # http://localhost:3001
```

## 项目优势（科创/答辩/简历用）
- 精准解决科研学生真实痛点：替代笨重专业文献软件，轻量化即用即走
- AI 赋能科研效率：自动精读、翻译、提炼、对比，降低文献阅读门槛
- 笔记文献强联动，解决笔记散乱无法复盘
- 国标引用一键导出，解决论文排版最大痛点
- 特色功能差异化强：卡片可视化管理、期刊溯源、平行文献双层检索、对比界面一站式批量管理
