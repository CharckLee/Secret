AI文献精读与轻量化管理平台 · claude.md（大学生科创/毕设/作品集可用）
1. 项目概述
1.1 项目定位
面向大学生、生物医药、理工科科研人员的轻量化AI文献管理精读Web平台。
摒弃 Zotero、EndNote 臃肿复杂、启动慢、操作繁琐、笔记割裂、无法快速精读的问题。
主打：轻量、即用即走、AI自动解析、笔记联动、一键国标引用。
1.2 真实痛点（项目核心价值）
- Zotero/EndNote 太重、配置繁琐、不适合学生快速上手
- 大量PDF文献堆积，无法快速筛选核心结论
- 英文文献难懂、逐篇精读耗时极大
- 文献笔记零散，和原文无法联动对照
- 写论文参考文献格式混乱，手动改 GB/T7714 极其耗时
- 多篇文献观点无法横向对比、梳理研究差异
1.3 技术栈（固定，全程不许改动）
Next.js 16 + TypeScript + TailwindCSS + Prisma + SQLite + 前端文件解析
纯轻量化本地项目，无需复杂部署、无需后端服务器、适合课程项目/科创作品/作品集。
1.4 开发原则（硬性约束）
- 极简、高速、无冗余功能
- 学生科研刚需优先，不做花里胡哨的社区、社交、付费功能
- 所有文献、笔记本地存储，保证轻量化
- UI 学术简约风、干净高级、适合科创展示
2. 核心功能清单（精准落地）
2.1 PDF文献上传与智能解析
- 支持单篇/批量 PDF 上传
- 自动解析 PDF 文本内容
- 自动提取：标题、作者、摘要、关键段落、研究方法、实验结论
- 上传卡片 hover 轻微放大、阴影加深，交互干净高级
2.2 AI 文献智能精读模块（核心亮点）
对解析后的全文进行 AI 结构化提炼：
- 自动生成中文摘要
- 自动提取 5–10 个核心关键词
- 自动梳理：研究目的、实验方法、创新点、局限性、核心结论
- 英文文献自动翻译关键段落，降低阅读门槛
2.3 标签分类管理系统
- 自定义标签创建、编辑、删除
- 文献多标签绑定
- 按标签筛选文献库，快速定位对应研究方向文献
- 支持搜索文献标题、关键词、正文内容
2.4 文献专属笔记联动系统（解决笔记散乱痛点）
- 每篇文献独立笔记面板
- 支持富文本简单笔记录入
- 笔记与文献永久绑定，点开文献即可看到对应学习记录
- 自动保存笔记，无需手动保存
2.5 多文献平行对比分析系统（核心特色功能）
- 支持勾选 2–3 篇文献进行横向对比
- AI自动输出对比维度：研究对象、实验方法、数据结果、创新点、不足
- 帮助学生快速梳理研究现状、撰写综述
2.6 国标参考文献导出（GB/T7714）
- 一键生成国家标准 GB/T7714 参考文献格式
- 支持单篇导出、多篇批量导出
- 可直接复制粘贴到论文，无需手动排版
2.8 平行文档智能对比+关键词专属检索功能（核心升级）
优化原有文献对比功能，支持多篇平行文献横向对比，新增专属关键词智能总结检索逻辑，区分「全局内容总结」和「精准位置跳转」双模式，完全贴合科研查阅需求。
- 平行文档对比逻辑：所有参与对比的文献为平等平行关系，无主次区分，统一排版展示核心内容，支持2–5篇文献同时对比
- 关键词智能总结功能：对比界面内置关键词搜索框，输入任意科研关键词，系统不检索位置，即时独立总结每篇文献中围绕该关键词展开的核心观点、研究内容、实验结论、相关论述，以独立区块分文献展示，直观横向对比差异
- 专属功能按钮：对比界面固定角落放置「搜索位置」功能按键，按钮自带hover悬浮放大、阴影加深鼠标交互反馈，点击按钮后，自动跳转至专属检索页面，精准定位每篇文献中该关键词的全部出现位置，并高亮展示
- 支持关键词切换、实时刷新总结内容，无需刷新页面，交互流畅
2.7 平行文档智能对比+关键词专属检索功能（核心升级）
2.9 对比界面批量论文管理功能（全新集成功能）
无需返回文献列表页，在对比界面直接实现论文批量管理，提升文献整理效率，所有操作实时同步数据库。
- 批量操作功能：对比界面支持批量勾选多篇文献，实现批量删除、批量修改标签、批量归类、批量导出引用格式
- 单篇快捷管理：支持在对比区块单独对单篇文献编辑信息、新增笔记、单独导出、移除对比列表
- 操作交互：所有管理按钮自带hover交互反馈，操作后即时刷新页面数据，无卡顿、无数据残留
- 适配全部文献来源：兼容本地上传PDF、爬虫抓取的期刊论文，统一管理逻辑
3. 页面结构设计
3.1 首页 - 文献库总览（全新改版）
- 顶部功能区：搜索框 + 标签筛选 + 文献上传按钮 + 【进入对比板块】功能按钮
- 全局文献展示样式：全部采用矩形圆角卡片方块布局，统一尺寸、排版规整、学术简约风格
- 卡片交互规范：适配全站统一hover效果，鼠标悬浮时轻微放大（scale 1.02）、阴影加深、200ms平滑过渡
- 单篇文献卡片固定展示信息（完整基础信息）：论文标题、作者、发表时间、核心标签、期刊来源地址/期刊名称来源信息
- 期刊地址信息作用：完整保留论文来源溯源信息，适配学生撰写综述、论文文末标注参考文献来源场景，无需手动查阅溯源
- 卡片点击逻辑（全新规范）：首次点击卡片进入论文简述预览页，展示文献摘要、核心结论、关键词等精简信息；简述页面内置【查看原文】按钮，点击后跳转完整原文精读详情页
- 对比板块入口逻辑：首页固定展示【进入对比板块】按钮，hover有交互反馈，点击后进入文献选择状态，支持批量勾选多篇文献，确认后直接跳转平行文献对比界面，无缝衔接全部对比、关键词检索、批量管理功能
- 卡片支持批量勾选功能，可直接在首页选中目标文献，快速加入对比列表
- 顶部功能区：搜索框 + 标签筛选 + 文献上传按钮 + 期刊爬虫入口按钮 +【进入对比板块】功能按钮
- 全局文献展示样式：全部采用矩形圆角卡片方块布局，统一尺寸、排版规整、学术简约风格
- 卡片交互规范：适配全站统一hover效果，鼠标悬浮时轻微放大（scale 1.02）、阴影加深、200ms平滑过渡，点击可进入文献详情页
- 单篇文献卡片固定展示信息（完整基础信息）：论文标题、作者、发表时间、核心标签、期刊来源地址/期刊名称来源信息
- 期刊地址信息作用：完整保留论文来源溯源信息，适配学生撰写综述、论文文末标注参考文献来源场景，无需手动查阅溯源
- 对比板块入口逻辑：首页固定展示【进入对比板块】按钮，hover有交互反馈，点击后进入文献选择状态，支持批量勾选多篇文献，确认后直接跳转平行文献对比界面，无缝衔接全部对比、关键词检索、批量管理功能
- 卡片支持批量勾选功能，可直接在首页选中目标文献，快速加入对比列表
- 顶部搜索框 + 标签筛选
- 上传文献按钮
- 文献卡片网格展示
- 卡片信息：标题、上传时间、标签、摘要预览
- hover 悬浮放大 + 阴影加深，点击进入文献详情页
3.2 文献详情 / AI精读页
- PDF在线预览
- AI结构化精读结果展示
- 关键词标签展示
- 侧边笔记编辑区
- GB/T7714引用导出按钮
3.3 文献对比页（全面升级，新增全部交互功能）
- 支持2–5篇平行文献同时加入对比，文献平等展示、无主次层级区分
- 顶部内置专属关键词搜索框，输入关键词后，实时为每篇文献独立生成关键词关联内容总结，分区块展示各文献围绕该关键词的核心论述
- 页面固定角落设置「搜索位置」功能按钮，按钮适配全局hover交互规范（scale 1.02、shadow-lg、200ms平滑过渡），鼠标悬浮、点击均有清晰反馈
- 点击「搜索位置」按钮，跳转专属关键词定位页面，高亮展示每篇文献中关键词的全部出现位置，支持上下翻阅定位
- 对比界面内置批量管理工具栏：支持批量勾选文献，完成批量删除、批量改标签、批量导出引用、批量归类操作
- 单篇文献区块内置快捷管理按钮：单独移除对比、编辑笔记、修改标签、单篇导出
- AI自动生成多维度对比分析报告（研究对象、实验方法、创新点、不足、结论），支持一键复制用于论文综述撰写
